How it works

The panel is built once and kept alive, so opening it is just showing it.

Carbon hotkey

Registers Command-Space with RegisterEventHotKey. No Accessibility permission needed.

→

Floating panel

Borderless, non-activating, so your app stays in front.

→

AppIndex

Scans /Applications, ~/Applications and system app folders. Ranks by fuzzy score plus how often you open each app.

→

fuzzyScore

Pure function in BeamCore, covered by a unit test.
